# CSS Übung: Position & z-index

In dieser Übung teste ich verschiedene CSS-Positionierungsmöglichkeiten und Ebenensteuerung mit `z-index`.

## Geübte Konzepte

- `static`: Standardpositionierung im Dokumentenfluss
- `relative`: Leichte Verschiebung vom Ursprungsplatz
- `absolute`: Frei platzierbar innerhalb eines Containers
- `fixed`: Immer sichtbar, unabhängig vom Scrollen
- `z-index`: Überlagerung von Elementen steuern

## Aufbau

- Jede Positionierungsart ist im HTML kommentiert dargestellt.
- Farbige Boxen helfen beim visuellen Verständnis.
- Der `z-index`-Abschnitt zeigt, wie sich Boxen überlappen.
